Dear friends of JSXGraph,

JSXGraph v1.14.0 finally delivers the long-overdue upgrade from jsdoc 2 to jsdoc 3 (v4.0.5) for the API reference; see <https://jsxgraph.org/docs/>. Readability has improved dramatically — even for us developers. As we expect further improvements to the API reference in the near future, we will now publish updates to it independently of JSXGraph releases.

*Call for help:* If you spot bugs or better wording in the API reference, please do not hesitate to contact us — on GitHub, in the forum (<https://forum.jsxgraph.com>), or by email.

The other major change affects the API reference because it fixes a bug that has been present in the sources since at least v1.0.0, found by Tom Berend. The affected elements are Sector, Arc, MajorArc, MajorSector, MinorArc, MinorSector, Parallel, ArrowParallel, Bisector, Circumcenter, Circumcircle, CircumcircleArc, CircumcircleSector, Incenter, Incircle, OrthogonalProjection, ParallelPoint, Perpendicular, PerpendicularPoint, PerpendicularSegment, and Semicircle.

When a defining point for one of these elements was supplied as a coordinate array rather than as an existing point, JSXGraph created an implicit parent point. Such parent points could

- inherit the name of the child element,
- receive an automatically generated name like `'A'` or `'B'`,
- be visible by default.

Starting with v1.14.0, these parent points

- are invisible by default and have the empty string `''` as their name,
- can be modified later via their sub-object, e.g.
  `sector.radiusPoint.setAttribute({visible: false});`

Enjoy, Alfred
