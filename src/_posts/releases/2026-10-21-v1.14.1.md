JSXGraph v1.14.1 delivers several important bug fixes.

The most important fix concerns JSXGraph boards that are invisible or hidden at initialization time: these are now resized correctly once they become visible. This issue has become increasingly relevant with modern web design practices. We thank Andrey Chesnokov (NTNU, Norway) for identifying and resolving this issue. If you still encounter resizing problems, we would be happy to receive bug reports.

In addition, we fixed a regression in `setLayer()` of the SVG renderer and repaired the broken gradient color management in the canvas renderer. The remaining bug fixes mostly address edge cases in numerical algorithms or other very specific situations.

We also moved the unused, largely legacy source code from `src/unused` to `src_unused`, since several AI agents had complained about the code quality of this old code.

As for code quality, the plans for the next major release (v1.15) are to remove the obsolete VML renderer for old Internet Explorer versions and to upgrade the LR parser for the JessieCode language.

Enjoy, Alfred
